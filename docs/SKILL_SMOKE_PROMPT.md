Используй $verification-before-completion для безопасной проверки подключения навыков EINEIRO.

Работай в /workspace/EP-Base. Это проверка в новой сессии, без изменений проекта.
Не устанавливай пакеты, не читай секреты и переменные окружения, не открывай БД/backup,
не запускай приложение, не обращайся к внешним сервисам, не публикуй и не делегируй работу.

1. Покажи `git rev-parse HEAD` и рабочий каталог. Если ожидаемый commit из предыдущего
   отчёта доступен в задании, сравни их. Без сравнения не утверждай, что snapshot восстановлен.
2. Проверь именно свой начальный каталог доступных навыков. Сравни его проектные имена,
   описания и пути с 33 записями docs/skills-lock.json. Не выдавай содержимое реестра или
   найденные файлы за результат штатного обнаружения. Если доступа к каталогу нет, укажи это.
3. Прочитай AGENTS.md и применимый навык. Если он отсутствует в каталоге, можно явно прочитать
   .agents/skills/verification-before-completion/SKILL.md, обозначив это как fallback.
4. Выполни `python3 scripts/check-skills.py`. Укажи наблюдаемый exit code и краткий результат.
   Объясни, как применено требование навыка о свежих доказательствах перед заявлением успеха.
5. Отдельно сообщи: файлы/метаданные проверены; native discovery подтверждено или недоступно;
   выбранный навык применён; восстановление commit подтверждено или не проверено.
   Не считай проверку подключения полностью пройденной при недоступном native discovery.

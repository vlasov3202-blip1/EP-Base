# Дизайн-навыки EINEIRO

Навыки находятся в проекте, в `.agents/skills/`. Агент может читать их непосредственно по путям ниже. Штатное обнаружение зависит от каталога запуска и исправности клиента; в текущем облачном профиле оно заблокировано до загрузки навыков. [Проверки и запуск новой сессии](CLOUD_SKILLS.md).

| Навык | Локальный путь / вызов | Назначение | Источник |
|---|---|---|---|
| Impeccable 4.6.0 | `.agents/skills/impeccable/SKILL.md`, `$impeccable` | UX, композиция, адаптивность, доступность, аудит и полировка | [pbakaus/impeccable](https://github.com/pbakaus/impeccable), [сайт](https://impeccable.style) |
| Taste Skill | `.agents/skills/design-taste-frontend/SKILL.md`, `$design-taste-frontend` | Визуальное направление и проверка интерфейса в браузере | [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill), [сайт](https://tasteskill.dev) |
| Emil design engineering | `.agents/skills/emil-design-eng/SKILL.md`, `$emil-design-eng` | Анимации, взаимодействия, производительность и детали UI | [emilkowalski/skills](https://github.com/emilkowalski/skills), [сайт](https://emilkowal.ski/skill) |

В исходном запросе адреса `tasteskill.sev` и `emilkoval.ski/skill` содержали опечатки. Названия и авторские репозитории сверены по их README. Сайты не доступны через текущую сетевую политику среды; загрузка выполнена через разрешённый GitHub. Дополнительные секреты не нужны.

Полные инструкции, справочники, вспомогательные файлы и лицензии сохранены вместе. SHA коммитов и SHA-256 каждого файла находятся в [design-skills-lock.json](design-skills-lock.json). Обновление навыков — явное действие: сравнить upstream, сохранить лицензии, обновить манифест. Автоматического обновления при запуске приложения нет.

Impeccable содержит штатный launcher и загружает проверяемый по SHA-256 engine. В этой среде проверен `engine-probe` (0.1.15); кэш — `/workspace/.cache/impeccable`. Для нового окружения:

```bash
IMPECCABLE_HOME=/workspace/.cache/impeccable IMPECCABLE_NO_TELEMETRY=1 \
  .agents/skills/impeccable/scripts/impeccable engine-probe
```

Taste Skill требует Node.js 22+ и Chrome/Chromium для браузерного инспектора; они доступны в текущей среде. Скрипт выбора направлений запускается без дополнительных npm-зависимостей. Браузерные проверки приложения выбираются по фактическим scripts текущего checkout; установка навыка не добавляет их в package.json. Сам инспектор upstream не перенастраивался. Поиск изображений использует внешние сайты и проверяется отдельно при необходимости. Навык Emil — Markdown-инструкции без runtime-зависимостей. Установка этих файлов сама по себе не означает прохождение дизайн-аудита приложения.

Примеры будущих задач:

- «Используй `$impeccable` для аудита страницы товаров Business, сохрани существующие действия».
- «Используй `$design-taste-frontend` для визуального направления Admin; это рабочий интерфейс».
- «Используй `$emil-design-eng` для открытия каталога Market с поддержкой reduced motion».

Согласованные правила EINEIRO имеют приоритет: Camera Safe Zone, независимые каталоги объектов, отдельные Market/Business/Admin, управление по исключениям. Новый визуальный стиль и механики не выбираются установкой навыков.

## Коммерческое использование

Проверены лицензии именно установленных версий, закреплённых в `design-skills-lock.json`:

| Навык | Лицензия | Коммерческое использование |
|---|---|---|
| Impeccable | [Apache-2.0](../.agents/skills/impeccable/LICENSE) | Разрешено |
| Taste Skill | [MIT](../.agents/skills/design-taste-frontend/LICENSE) | Разрешено |
| Emil design engineering | [MIT](../.agents/skills/emil-design-eng/LICENSE) | Разрешено |

Эти лицензии позволяют применять навыки при разработке платного и закрытого продукта, без лицензионных отчислений за такое использование и без обязанности открывать исходники EINEIRO. При распространении самих навыков или включённых в продукт существенных фрагментов их материалов нужно сохранять лицензии и авторские уведомления. Для Apache-2.0 также сохраняются применимые NOTICE и отмечаются изменения распространяемых файлов. В установленном Impeccable сохранён [NOTICE.md](../.agents/skills/impeccable/NOTICE.md), включая сведения о сторонних MIT-материалах.

Лицензии и уведомления уже находятся рядом с установленными навыками. Они не дают автоматически прав на любые найденные навыком фотографии, шрифты, логотипы или внешние сервисы: такие ресурсы проверяются по собственным условиям. Условия AI-сервиса также отдельны от лицензии навыка.

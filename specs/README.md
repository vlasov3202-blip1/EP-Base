# Спецификации EINEIRO

Со следующей существенной механики здесь хранятся каталоги `<number>-<feature>` с
`spec.md`, `plan.md` и `tasks.md`. Конкретная механика ещё не выбрана.

Перед работой прочитайте [конституцию](../.specify/memory/constitution.md) и
[порядок применения Spec Kit](../docs/SPEC_KIT.md). Спецификации меняются вместе с
согласованными изменениями поведения; предыдущие решения сохраняются в истории Git.

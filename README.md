# EP Base

Мобильная рабочая система учёта склада и продаж автозапчастей проекта **Easy Parts**.

## Что уже работает — MVP 0.2

- адаптивная главная панель;
- каталог деталей с поиском и фильтрами;
- добавление детали с автоматическим EP-кодом;
- заводской OEM-артикул и несколько кросс-номеров;
- применяемость, состояние и описание дефектов;
- поиск по названию, EP-коду, OEM и кросс-номерам;
- генерация этикетки 58 × 40 мм со штрих-кодом Code 128;
- шаблоны объявлений для Авито, Дром и Auto.ru;
- автомобили-доноры, складские адреса, статусы и финансовая сводка;
- сохранение изменений на текущем устройстве.

## Задача проекта

Единая база для:

- автомобилей-доноров;
- снятых запчастей и их фактического места на складе;
- фотографий, состояния и применяемости деталей;
- публикаций, броней и продаж;
- расходов, выручки и прибыли по каждому автомобилю;
- задач по разбору, подготовке и выдаче товара.

## Следующий этап

1. Подключить общую облачную базу вместо хранения на одном устройстве.
2. Добавить авторизацию и роли: владелец, разборщик/кладовщик, продавец.
3. Добавить фотографии деталей.
4. Добавить отдельные карточки продаж и расходов.
5. Подготовить импорт текущих складских остатков.

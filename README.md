# EP Base

Мобильная рабочая система учёта склада и продаж автозапчастей проекта **Easy Parts**.

## Что уже работает — MVP 0.3

- общая облачная база с автоматическим переносом данных с текущего устройства;
- роли владельца, склада и продавца с серверной проверкой прав;
- отдельный набор разделов и действий для каждой роли;
- добавление сотрудников по email;
- сканирование штрих-кода Code 128 камерой телефона;
- ручной поиск по EP-коду как запасной вариант;
- каталог деталей, OEM-артикулы, кросс-номера и применяемость;
- этикетки 58 × 40 мм и шаблоны объявлений для Авито, Дром и Auto.ru;
- автомобили-доноры, складские адреса, статусы и финансовая сводка.

## Рабочая версия

## Локальный запуск

```bash
npm run dev
```

Проверка и сборка:

```bash
npm run check
npm run build
```

# EP Base

Мобильная рабочая система учёта склада и продаж автозапчастей проекта **Easy Parts**.

## Что уже работает — MVP 0.3

- общая облачная база с автоматическим переносом данных с текущего устройства;
- роли владельца, склада и продавца с серверной проверкой прав;
- отдельный набор разделов и действий для каждой роли;
- добавление сотрудников по email;
- сканирование штрих-кода Code 128 камерой телефона;
- ручной поиск по EP-коду как запасной вариант;
- каталог деталей, OEM-артикулы, кросс-номера и применяемость;
- этикетки 58 × 40 мм и шаблоны объявлений для Авито, Дром и Auto.ru;
- автомобили-доноры, складские адреса, статусы и финансовая сводка.

## Дизайн-навыки

В `.agents/skills/` установлены Impeccable, Taste Skill и основной навык дизайн-инженерии/анимаций Emil Kowalski. Источники, версии, требования и примеры вызова: [docs/DESIGN_SKILLS.md](docs/DESIGN_SKILLS.md). Правила проекта для агентов: [AGENTS.md](AGENTS.md).

Текущие интерфейсы содержат демонстрационные данные и локальные сценарии. Проверки разработки не означают production-готовность. Следующие механики и продуктовые изменения уточняются отдельными заданиями.

## Спецификации механик

Установлен GitHub Spec Kit 1.2.2 для Codex. Со следующей существенной механики используем спецификацию, план, задачи и сверку реализации. [Правила EINEIRO](.specify/memory/constitution.md) опираются на существующие продуктовые документы; [порядок работы и установка CLI](docs/SPEC_KIT.md).

В проекте 33 локальных навыка: дизайн, Spec Kit, маркетинг/SEO, качество интерфейса, Playwright, Sentry, три выбранных навыка Superpowers и `eineiro-safe-migrations`. [Состав, лицензии, совместимость и ограничения обнаружения](docs/SKILLS.md), [закреплённые источники и контрольные суммы](docs/skills-lock.json). Проверка: `python scripts/check-skills.py`.

Облачная загрузка без переустановки: `bash scripts/cloud-skills-setup.sh`. [Настройка среды, текущая блокировка Codex и проверка новой сессии](docs/CLOUD_SKILLS.md); [готовое безопасное задание](docs/SKILL_SMOKE_PROMPT.md).

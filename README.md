# EP Base

Рабочая система учёта склада и продаж автозапчастей проекта **Easy Parts**.

## Задача проекта

Единая база для:

- автомобилей-доноров;
- снятых запчастей и их фактического места на складе;
- фотографий, состояния и применяемости деталей;
- публикаций, броней и продаж;
- расходов, выручки и прибыли по каждому автомобилю;
- задач по разбору, подготовке и выдаче товара.

## Первый этап — MVP

1. Главная панель.
2. Карточки автомобилей-доноров.
3. Каталог запчастей.
4. Склад: зона → стеллаж → полка, без обязательных ячеек.
5. Статусы детали: снята, подготовлена, опубликована, забронирована, продана.
6. Продажи и финансовый результат.
7. Роли: владелец, разборщик/кладовщик, продавец.
